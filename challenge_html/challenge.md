# 🚀 Reto Técnico Front-End

¡Bienvenido al reto técnico! El objetivo de esta prueba no es evaluar sintaxis de memoria, sino tu criterio de **maquetación**, estructura HTML/CSS, resolución de problemas y cómo manejas la lógica básica de interacción.

---

## 🛠️ Instrucciones de inicio

1. Realiza un **Fork** de este repositorio en tu cuenta personal de GitHub.
2. Clona tu fork localmente o ábrelo en un entorno online (Codespaces, StackBlitz, CodePen, etc.).
3. No necesitas instalar dependencias ni herramientas de build: basta con abrir `index.html` en el navegador (o usar una extensión como Live Server).

## 📋 Requisitos del Reto

### 1. Maquetación (HTML + CSS)
- Construye la interfaz usando únicamente **HTML5 y CSS3** (sin frameworks ni librerías de componentes).
- Cuida la semántica HTML (`<main>`, `<form>`, `<label>`, `<button>`, etc.) y la accesibilidad básica (labels asociados a sus inputs, foco visible).
- Cuidado visual con tipografías, espaciados (padding, gap), bordes y alineación.
- Organiza tus estilos de forma clara (por ejemplo, variables CSS para colores y espaciados).

### 2. Mensajes de Error (JavaScript)
- Usa **JavaScript vanilla** (sin librerías ni frameworks) en un archivo `script.js` separado.
- Implementa la lógica para que, al intentar enviar el formulario con algún campo vacío o inválido (por ejemplo, un email con formato incorrecto), se muestren mensajes de error junto a cada campo.
- Los mensajes deben desaparecer o actualizarse cuando el usuario corrija el valor.

### 3. Extra / Plus (Opcional pero valorado)
- **Diseño Responsivo:** que el formulario se adapte de forma fluida a pantallas móviles y de escritorio (media queries, Flexbox/Grid).
- Interacciones extra con JS puro, como mostrar/ocultar la contraseña o alternar entre Login y Registro.
